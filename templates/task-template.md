# Codex Task Template

## Objective
Describe one concrete outcome.

## Context
Provide only the repository, files, constraints, and prior decisions needed to do the task correctly.

## Requirements
1. State required behavior.
2. State compatibility constraints.
3. State files/data that must not be modified.
4. State validation expectations.

## Workflow
1. Inspect relevant repository context.
2. Produce a concise implementation plan for non-trivial work.
3. Work on a dedicated branch.
4. Implement the smallest complete solution.
5. Run available tests/checks.
6. Review the final diff.
7. Create a Draft Pull Request.

## PR requirements
Include:
- Summary
- Rationale
- Files changed
- Validation/tests
- Known limitations

Do not merge unless explicitly instructed.
